# Skill: UI/UX and Accessibility Standards

Guidelines for building premium, accessible user interfaces using PrimeNG and Tailwind CSS.

## Styling Frameworks
- **Tailwind CSS**: Use Tailwind for all layout and component styling.
- **PrimeNG**: Use PrimeNG components for complex UI elements (tables, trees, forms).
- **Design Consistency**: Maintain a professional, premium look consistent with the Indigo/Oceanic theme.

## Accessibility (A11y)
- Must pass all AXE checks.
- Must follow WCAG AA standards (focus management, contrast, ARIA).

## Best Practices
- Avoid `any` type; use strict TypeScript.
- Use `unknown` for uncertain types.
- Follow the official Angular [Style Guide](https://angular.dev/style-guide).
