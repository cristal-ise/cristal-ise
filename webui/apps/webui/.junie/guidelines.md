# WebUI Application Guidelines

## Purpose
The main user interface for CRISTAL-iSE applications, built with Angular.

## Technology Stack
- **Angular 19**.
- **PrimeNG 19**.
- **Tailwind CSS**.

## Key Features
- Dynamic form generation based on Item descriptions.
- Workflow and activity execution for users.
- Custom dashboard and reports.

## Guidelines for Junie
- Ensure consistent UI/UX with the `admin` application.
- Leverage `libs/core` for all shared business logic and services.
- Follow established patterns for state management and API communication.
