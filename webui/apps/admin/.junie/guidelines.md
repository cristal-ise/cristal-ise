# WebUI Admin Application Guidelines

## Purpose
Main administrative Angular application for CRISTAL-iSE. Provides tools for managing domains, items, and workflows through a modern web interface.

## Technology Stack
- **Angular 19**: Framework.
- **PrimeNG 19**: UI component library.
- **Tailwind CSS**: Styling.

## Key Features
- Dashboard with domain tree.
- Item search and management.
- Configuration and layout management.
- Integration with `libs/core` for backend communication.

## Guidelines for Junie
- Follow the existing folder structure for layout and components.
- Ensure new features are consistent with the `webui` dashboard theme.
- Refer to `src/app/layout` for core layout components.
- Configure routes in `src/app/app-routing.module.ts`.
