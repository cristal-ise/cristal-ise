# DSL Module Guidelines

## Purpose
Domain Specific Language implementation for creating and updating CRISTAL-iSE kernel objects.

## Technology Stack
- **Groovy**: The DSL is implemented using Groovy.

## Key Components
- DSL scripts for object creation and update.

## Testing
- Check the `src/test` directory for examples and tests of the DSL.

## Guidelines for Junie
- DSL scripts are typically located in `src/main/module`.
- Ensure new DSL features follow existing syntax for Item creation and configuration.
- Use Groovy 4 features where appropriate.
